代表プロフィール

自治会・町内会・小規模事業者の皆さまにとって、ITやDXは「何から始めればよいかわからない」「誰に相談すればよいかわからない」と感じやすい分野です。

めたちゃんDX相談所では、ホームページ作成、PCやメールの設定、情報共有の見直し、Googleフォームの活用、業務のちょっとした効率化など、身近なITのお困りごとを、専門用語をできるだけ使わずにわかりやすく整理し、現場に合った形で支援しています。

代表は、移動体通信エンジニアを経て、ネットワークインフラエンジニアの道へ進みました。現在も本業では、ネットワークインフラの最前線で、ネットワーク、セキュリティ、ボイス、データセンター、クラウド連携、プロジェクトマネジメントなど、多岐にわたる分野に携わり、最新技術を活用したシステム提案・システム構築に取り組んでいます。

これまで20年以上にわたり、企業向けITインフラの現場で実務経験を積み、CCIE Enterprise Infrastructure、複数分野のCCNP、PMP、情報処理安全確保支援士などの資格も保有しています。

こうした専門的な経験や知識を、難しい言葉のまま伝えるのではなく、自治会・町内会・小規模事業者の皆さまにとって、身近で相談しやすい形に変えてお届けすることを大切にしています。

「こんなことを相談してもよいのかな？」という段階からでも大丈夫です。現場の状況に寄り添いながら、一緒に整理し、無理のないDX・IT活用を支援します。

主な保有資格：
CCIE Enterprise Infrastructure、CCNP Enterprise / Collaboration / Security / Data Center、PMP、情報処理安全確保支援士、テクニカルエンジニア（ネットワーク）、基本情報技術者 など
